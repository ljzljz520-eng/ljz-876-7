# 公务员面试打分系统

面向结构化公务员面试的打分与考务管理平台，零第三方依赖（仅 Python 3.8+ 标准库 + SQLite + 原生前端）。

## 启动

```bash
python3 server.py
# 打开 http://localhost:8000  （可用 PORT=9000 python3 server.py 改端口）
```

首次启动自动创建 `data.db` 并写入演示数据；删除该文件后重启可恢复初始演示数据。

## 功能与角色

### 考官端
- 查看本组考生（按序号），按四个维度独立打分：
  - 结构化题目 40 分
  - 仪态表达 20 分
  - 政策理解 20 分
  - 应变能力 20 分（合计 100 分，输入时实时校验与合计）
- 成绩发布前可反复修改本人评分；发布后锁定
- 存在回避关系的考生强制回避，无法打分

### 评分规则
- 有效分 = 本组考官提交的分数，**自动剔除回避/非本组考官的评分**
- **去掉一个最高分、一个最低分**后，对其余分数取算术平均（保留 2 位小数）
- 有效分不足 3 份时不出成绩、不可发布
- 评分进度 = 已交 /（本组考官数 − 回避考官数）

### 考务端
- **成绩管理**：打分进度总览、预计算成绩、逐人查看评分明细（标注最高/最低剔除、回避作废）、公布/撤回成绩
- **考务管理**：
  - 缺考登记/恢复（缺考自动清空评分、不可发布）
  - 考生换组（清空原评分、撤回已公布成绩、自动重新编号）
  - 考官换组（其在原组评分自动失效，回避记录保留备查）
  - 新增考生（自动生成账号，初始密码 123456）
- **回避管理**：登记/解除考官—考生回避关系及事由，登记即作废相关评分
- **申诉处理**：查看考生申诉并填写复核答复（待处理数量角标提醒）

### 考生端（信息最小化）
- 成绩未公布：仅显示"成绩尚未公布"
- 成绩公布后：只显示**最终成绩**与计分方式说明（看不到各考官、各维度打分）
- 缺考：显示"缺考，无面试成绩"
- 申诉入口：仅公布后开放，同一时间限一条待处理申诉，可查看考务答复

## 目录结构

```
server.py            后端：HTTP 服务、SQLite、评分计算、全部 API
static/index.html    单页应用入口
static/styles.css    样式
static/app.js        前端：登录 / 考官端 / 考务端 / 考生端
data.db              首次运行自动生成
```

## 主要 API

- `POST /api/login`、`POST /api/logout`、`GET /api/me`
- 考官：`GET /api/examiner/candidates`、`POST /api/examiner/score`
- 考务：`GET /api/staff/overview`、`GET /api/staff/result`、
  `POST /api/staff/publish | unpublish | absent | move-candidate | move-examiner |
  recusal | recusal/remove | candidate | reply-appeal`
- 考生：`GET /api/candidate/score`、`GET /api/candidate/appeals`、`POST /api/candidate/appeal`

认证使用随机 Token（请求头 `X-Auth-Token`），所有接口均有角色与数据归属校验。
