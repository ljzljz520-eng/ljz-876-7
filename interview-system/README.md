# 公务员面试打分系统

零依赖（Node.js 内置模块），开箱即用。数据持久化在 `data/data.json`。

## 启动

```bash
node server.js        # 默认端口 3000，可用 PORT 环境变量修改
```

访问 http://localhost:3000

## 三端功能

| 角色 | 功能 |
|------|------|
| 考官 | 按「结构化题目40% / 仪态表达20% / 政策理解20% / 应变能力20%」四维度评分，可修改本人评分 |
| 考务 | 考生缺考标记/恢复、换组（自动清除原评分）、回避关系建立/解除（回避后评分作废）、成绩发布/撤回、申诉回复 |
| 考生 | 凭准考证号+姓名查询**最终成绩**，成绩公布后可在线申诉 |

## 计分规则

1. 每位考官的评分 = 四维度加权合成（满分100）
2. 同一考生的全部有效考官评分中，**去掉一个最高分和一个最低分**，取其余平均分作为最终成绩
3. 有效评分不足 3 人时显示「评分不足」，不生成成绩
4. 缺考考生不参与计分；存在回避关系的考官评分自动剔除

## 目录结构

```
├── server.js        # HTTP 服务 + API 路由 + 计分逻辑
├── lib/auth.js      # HMAC 令牌
├── lib/db.js        # JSON 持久化 + 种子数据
├── public/          # 前端页面（登录/考官/考务/考生）
└── data/data.json   # 运行时生成的数据文件
```
